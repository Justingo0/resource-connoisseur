# Resource Connoisseur

Resource Connoisseur is a game similar to Mindustry (our inspiration), Factorio, and many other factory type games, and we decided that if we like these games so much, why don't we make one of our own!  Resource connoisseur is a game where you mine and then use those resources to make buildings and fuel your weapons of mass destruction (wip)

----

## Features

- Conveyors
- Conveyors are able to convey things
- Ores to mine
- Grid snapping system
- A core that allows depositing resources
- Map dragging

----

## How To Play

In order to play the game, go to the itch page that is provided in the github, install the game, extract the zip, and then play the game!

----

## Made Using

We used the Godot Engine to make this game, and we also used pixilart (I did this) to make our sprites!
