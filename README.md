Resource Connoisseur is a sandbox game, where you gather resources and bring it back to base to unlock new machines and better equipment.

# Features
- Ore Mining
- Grid Placement System
​- Item Movement with Conveyors
- Object Selection
- Object Deletion
- Conveyor Splitting
- Core Depositing
- Camera Movement
- Player Character

----

# How To Play?
​Start by placing a miner over some ore. Then place conveyors from the miner to base. Then expand your factory and your resource input.

WASD to move ​OR ​drag click with either Left Mouse Button or Middle Mouse Button.
