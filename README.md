**Resource Connoisseur** is a sandbox game, where you gather resources and bring it back to base to unlock new machines and better equipment.

# Features
* Ore Mining
* Grid Placement System
* Item Movement with Conveyors
* Conveyor Splitting
* Ore Depositing
* Camera Movement
* Player Character
* Pausing
* Turret Shooting
* Enemy Spawning
* Wave System
* Wave Skipping
* Enemy Movement
* Sequential Placing & Deleting
* Conveyor Splitter
# How To Play?
​**WASD** to move.​

Start by placing a **Miner** over some **Ore**. Then place **Conveyors** from the **Miner** to **Base**. Then build more **Miners**, until every **Ore** is covered!
